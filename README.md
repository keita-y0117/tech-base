# TECH-BASE PHP Learning Portfolio

TECH-BASEのカリキュラムを通じて、PHPの基礎からデータベースを利用した掲示板まで段階的に制作した学習リポジトリです。

## 制作したもの

最終課題では、PHPとMySQLを利用したパスワード付き掲示板を実装しています。

- 名前・コメント・パスワードを入力する新規投稿
- データベースに保存された投稿の一覧表示
- 投稿番号とパスワードによる本人確認
- 本人確認に成功した投稿だけを編集・削除
- 編集後も投稿時のパスワードを維持
- 入力不足やパスワード不一致時のメッセージ表示

完成版は [`MIssion5/m5-04.php`](MIssion5/m5-04.php) です。

## 工夫した点

### 安全なデータベース操作

SQLにはPDOのプリペアドステートメントを使用し、入力値をSQL文へ直接連結しない構成にしました。

### パスワードの保護

投稿パスワードは平文ではなく `password_hash()` でハッシュ化して保存し、編集・削除時は `password_verify()` で照合しています。

### 安全な画面表示

投稿内容を表示する際は `htmlspecialchars()` を使用し、入力されたHTMLがそのまま実行されないよう対策しています。

### 接続情報の分離

データベースの認証情報はソースコードから分離しています。ローカル設定ファイルは `.gitignore` の対象としており、GitHubには公開されません。

## ローカルでの実行方法

### 必要な環境

- PHPが動作するWebサーバー
- MySQL
- XAMPPなどのローカル開発環境

### データベース設定

1. このリポジトリをXAMPPの `htdocs` 配下に配置します。
2. `db_config.example.php` をコピーし、ファイル名を `db_config.php` に変更します。
3. `db_config.php` に自分のデータベース名、ユーザー名、パスワードを設定します。
4. ApacheとMySQLを起動します。
5. ブラウザから `MIssion5/m5-04.php` を開きます。

`m5-04.php` の初回実行時に掲示板テーブルが作成されます。以前の課題で作成したテーブルにパスワード列がない場合は、自動的に追加されます。

## リポジトリ構成

```text
tech-base/
├─ Mission1/                 PHP基礎
├─ Mission2/                 フォームとファイル保存
├─ Mission3/                 ファイルベース掲示板
├─ Mission4/                 MySQL基礎
├─ MIssion5/                 MySQL掲示板
│  └─ m5-04.php              パスワード付き掲示板（完成版）
├─ db_connect.php            共通のDB接続処理
└─ db_config.example.php     DB設定の記入例
```
