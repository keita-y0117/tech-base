# TECH-BASE exercises

TECH-BASEで作成したPHPの学習課題をまとめたリポジトリです。

## データベース設定

データベースの接続情報はGitHubへ公開しません。

1. `db_config.example.php` を `db_config.php` という名前でコピーします。
2. `db_config.php` に自分のデータベース名、ユーザー名、パスワードを入力します。
3. XAMPPの公開フォルダにこのリポジトリを配置して、各PHPファイルを実行します。

`db_config.php` は `.gitignore` に登録されているため、Gitの公開対象にはなりません。
